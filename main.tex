\begin{frame}{Framing the Question}
\begin{columns}[T]
\begin{column}{0.58\textwidth}
\begin{block}{Main question}
\small
At first glance, the project confirms textbook diode theory. The more useful question is: where does the analytical model work, and where does the numerical model reveal non-ideal effects?
\end{block}

\begin{block}{Simulation workflow}
\begin{itemize}
    \item Equilibrium $\rightarrow$ extract $\vbi$ and $W$
    \item Dark J--V $\rightarrow$ fit $\jzero$
    \item Illuminated J--V $\rightarrow$ extract $\jsc$ and $\voc$
\end{itemize}
\end{block}
\end{column}

\begin{column}{0.38\textwidth}
\textbf{Three observations}
\begin{itemize}
    \item Electrostatics is robust.
    \item Current parameters deviate more.
    \item PIN changes collection mechanism.
\end{itemize}
\end{column}
\end{columns}
\end{frame}

\begin{column}{0.48\textwidth}
\textbf{Ideal Diffusion Theory:}
\vspace{-0.2cm}
$$J_0 = \frac{qD_p p_{n0}}{L_p} + \frac{qD_n n_{p0}}{L_n}$$

\vspace{-0.1cm}
\begin{itemize}
    \item \textbf{Baseline $\jzero$:} Simulation is $7.6\times$ higher than the ideal model above.
    \item \textbf{Asymmetry flattened:} Ideal theory heavily depends on mobility differences ($\mu_n=1400$ vs $\mu_p=450~\text{cm}^2/\text{Vs}$). Non-ideal SRH currents flatten this ideal $N_A/N_D$ asymmetry in simulation.
    \item Finite thickness, surface/SRH recombination matter.
\end{itemize}
\end{column}
\end{columns}
\end{frame}

\begin{itemize}
    \item Thicker intrinsic layer increases generation volume.
    \item Same-thickness $|\jsc|$ is similar for p--n and PIN.
    \item PIN greatly widens $W$, changing collection from diffusion-heavy to drift-based.
\end{itemize}

\begin{frame}{Key Conclusions}
\begin{enumerate}
    \item Simple formulas robustly capture equilibrium electrostatics.
    \item Current-related quantities, especially $\jzero$, reveal non-ideal effects.
    \item PIN's main advantage is a wider depleted region and drift-based collection.
    \item Driftfusion shows both what textbook theory confirms and what it misses.
\end{enumerate}
